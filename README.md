# HackerOS
What is HackerOS? HackerOS is a Polish Linux distribution based on Debian testing/stable.

## Editions
HackerOS has 10 editions:

- Official Editon - The regular edition and the most important one for HackerOS.
- Cybersecurity Edition - The edition is mostly the same as the official one but aimed at cybersecurity. It has a stable Debian.
- NVIDIA Edition - Identical version to the official one but with Nvidia drivers installed. (frozen edition)
- Hydra Edition - has everything the same as HackerOS official edition but additionally has a special look partially inspired by the look of Garuda Linux.
- Gnome Edition - The official version is identical but with the Gnome graphical environment installed.
- Xfce Edition - The official version is identical but with the Xfce graphical environment installed.
- Blue Edition - An edition of HackerOS with some of its tools and a proprietary graphical environment.
- Gaming Edition - An edition with a game mode inspired by SteamOS or Bazzite. But intended for PC/laptops only.
- LTS Edition - An edition equipped with everything the official edition has, but with the Debian stable channel.
- Atomic Edition - Edition with read-only file system and atomic proprietary hammer package manager (BETA).
