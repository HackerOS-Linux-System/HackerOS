# Alternatywy dla narzędzi w HackerOS

HackerOS posiada własne alternatywy dla git/curl/nano/mc:
Żadnego z tych narzędzi nie musisz instalować są wbudowane w HackerOS.

- **getit** - alternatywa dla git/wget - pobieraj repozytoria github, konkretne pliki oraz katalogi z githuba/gitlaba.
- **hedit** - alternatywa dla nano.
- **ngt** - alternatywa dla mc.
